# CH32X035G8U6 最少元件电路（安卓、5V IO）

依据：[参考原理图](CH32X035SCH.pdf)第7页、[评估板说明书](CH32X035评估板说明书.pdf)第11页、[数据手册](41FD1633476ABC3FCEBDD89EB906E725.pdf)；接线见下表及 [电路图](G8U6最小电路.svg)，数量见 [BOM](G8U6-BOM.csv)。
目标：J1 6pin 接5V充电器，J2 16pin 给安卓手机供电并通过 [AOA](https://source.android.com/docs/core/interaction/accessories/protocol) 通信；一路输入、一路输出；USB ISP 通过治具烧录，手机须支持 AOA。
供电约束：选有过流保护、5V±5%且CC宣告3A的USB-C充电器及3A线缆；J2用无E-Marker的被动USB2.0数据线，宣告5V/1.5A；线缆及电源须使J2满载电压≥4.75V、U1电压≤5.25V。

| 部位 | 接线与数值；U1脚号按G8U6/QFN28，所有GND共地 |
| --- | --- |
| J1输入 | 所有VBUS→5V_SYS，所有GND及外壳→GND；CC1、CC2分别经R1、R2＝5.1kΩ到GND；6pin须确实引出两路CC。 |
| 输入能力检测 | J1 CC1→U1 PA2(7)，CC2→PA4(9)，配置ADC直接检测3A声明；这两路CC不能连接到J2的CC。 |
| U1最小系统 | CH32X035G8U6：VDD(2)→5V_SYS，裸露焊盘(0)→GND；C1＝100nF、C2＝10µF并接5V_SYS/GND并就近放置，兼作U2输入去耦。 |
| U2手机电源 | RT9742CGJ5（TSOT-23-5）：VIN→5V_SYS，VOUT→VBUS_PHONE，GND→GND，FLG悬空；内部固定限流典型2.2A（C档），带短路折返、过温、欠压锁定及软启动。立锜宣称反向电流阻断，但器件为单N-FET结构，体二极管在VOUT>VIN+0.6V时仍导通：无充电器时误插J2到带电主机会经体二极管向5V_SYS被动供电（约4.4V），不损坏；板载ISP方案将该路径用作USB-A电脑烧录供电，属有意利用，打样时验证。 |
| U2使能 | PA5(10)→U2 EN直连（高有效），EN经R4＝5.1kΩ到GND，复位/烧录时默认关闭；比原TPS25947方案省去串联电阻R3，EN为常规逻辑电平输入。 |
| 限流及放电 | 限流为芯片内部固定2.2A典型值（RT9742C档），无需ILM电阻；VBUS_PHONE→R7＝1kΩ→GND泄放（τ≈120ms、2.3τ≈280ms，留足650ms裕量），C3＝100µF/10V、±20%低ESR并接VBUS_PHONE/GND，注意极性。 |
| J2电源 | 所有VBUS→VBUS_PHONE，所有GND及外壳→GND；SBU1/SBU2悬空；不把J1、J2的VBUS直接并接。 |
| J2数据 | A6/B6就近并联→PC17/D+(27)，A7/B7就近并联→PC16/D−(26)；使用片内PHY及匹配电阻，不加外部上拉，不短接D+/D−。 |
| J2角色 | A5/CC1→PC14(28)，B5/CC2→PC15(1)；固件启用片内180µA上拉，设置Source；手机口不装5.1kΩ下拉，5V方案无需PD电压协商。 |
| 两路IO | H3端子2→PA0(5)为IN，H3端子1→5V_SYS，外接干接点短接两脚即输入高，输入启用内部下拉；PA1(6)→Q1(AO3401A P-MOS)栅极，R5＝1kΩ栅极上拉至5V_SYS；Q1源极→5V_SYS、漏极→H2端子2为OUT（5V功率输出，低电平开启、默认关断），H2端子1→GND。 |
| 烧录焊盘 | TP1＝5V_SYS、TP2＝GND、TP3＝D−、TP4＝D+（可选保留，兼容治具）；另预留PC18/DIO(25)、PC19/DCK(24)调试焊盘，焊盘不占BOM。 |
| 板载烧录按键 | 5V_SYS→R6＝1kΩ→SW1（常开）→D+（USB_DP）；按住SW1上电使PC17为高进ROM BOOT，实现空片/救砖USB ISP。 |

- 固件顺序：上电先关U2及J2上拉，等待650ms泄放；确认J1的3A声明后启用J2上拉，经CC附着消抖识别手机Rd才开启U2；拔出或输入能力下降时同时关闭U2及Rp，等650ms后从头检测附着；短路/过温由U2自动保护；拒绝供电角色交换。
- USB用内部48MHz时钟，选择5V供电的PHY配置，PC10/PC11保持浮空输入；实现USB Host＋AOA握手、Bulk收发；`READ_IN`返回0/1，`SET_OUT`经Q1低有效驱动OUT并应答（低=开启），断连/超时输出高电平关断OUT。
- 安卓App使用[UsbAccessory/openAccessory](https://developer.android.com/develop/connectivity/usb/accessory)；现有CH552固件及Android USB Host接口需要适配，此处是新电路设计，尚未实现新固件。
- USB ISP（板载按键方案）：按住SW1，J2接电脑USB-A口（供电经U2体二极管倒灌5V_SYS约4.4V，可接受）；Type-C口电脑不供VBUS，需同时J1接充电器供电；进BOOT后松开SW1，用WCHISPTool下载HEX/BIN。TP1～TP4治具方案可选保留作备份。
- J2运行时作手机口、烧录时作下载口，分时复用；烧录前先断开手机（固件须先关U2/Rp）；SW1误按仅拉高D+致通信中断，不损坏。
- 核心BOM共17件、13种规格：U1/U2/J1/J2/Q1各1，SW1/H2/H3端子各1；5.1kΩ×3（R1/R2/R4）、1kΩ×3（R5/R6/R7）；100nF/10µF/100µF各1；电阻均1%/0603，前两种电容选16V X7R。
- 相比评估板，省掉LDO、LED、指示电阻、供电选择开关，沿用片内时钟；下载按键改为板载（R6+SW1）；OUT改Q1高侧功率开关并配H2/H3接线端子；手机支路用U2替代原500mA保险丝用途；17件为功能版，不含ESD/浪涌选配器件。
- PCB保持USB差分约90Ω、完整地平面、烧录焊盘无长支线；C1贴近U1，C2紧靠U2 IN，C3贴近U2 OUT；5V路径按3A布线并实测线缆和开关压降；C2在5V偏压下有效容量≥1µF。
- PC17兼作BOOT：主动重启前关闭U2/Rp并等650ms，调用SystemReset_StartMode(Start_Mode_USER)再复位；手机连接下快速断电/看门狗复位可能先进入ROM，须验证自动恢复；异常时拔J2、断电≥1秒再上电。
- 打样验证正反插、AOA充电通信、IO（含Q1低有效OUT与H3干接点IN）、板载ISP（含体二极管倒灌4.4V下烧录）、短路/掉电/复位及热插拔峰值不超U1绝对最大5.5V；定值按 [U2原厂手册](https://www.richtek.com/Products/Power%20Switch/RT9742)（RT9742 V10.0），本设计未经实物验证。
