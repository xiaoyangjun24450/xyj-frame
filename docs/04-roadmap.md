# 任务排期和分阶段任务

目标：6 周跑通 Android MVP 闭环。原则：先验证关键技术，再做完整体验。

## 第 1 周：技术验证
- 验证 USB 转串口控制舱门。
- 做开门、关门 Demo。
- 验证 IMU 姿态识别和翻转触发。
- 做拍照上传 AI 判卷 Demo。
- 确认连续语音识别方案。
- 本周不做复杂 UI。

## 第 2 周：项目骨架
- 在当前 Android 项目内建立目录结构。
- 建 `model/`、`flow/`、`service/`、`repository/`。
- 做 `StudyFlow.kt` 状态机。
- 做学习计划 mock 数据和本地断点恢复。
- 做后端 API client 的 mock 接口。

## 第 3 周：主流程前半段
- 做启动页。
- 做学习计划选择页。
- 做权限和设备检查页。
- 做 USB 等待逻辑和辅导页面。
- 接语音转文字。
- 把学生输入发给 AI。

## 第 4 周：拍照判卷
- 做练习题页面。
- 接姿态触发和相机拍照。
- 上传图片和题目信息。
- 接 `/ai/grade`。
- 做判卷结果页。
- 跑通合格和重做分支。

## 第 5 周：考试和错题
- 做考试页面。
- 每题翻转交卷。
- 后台判分。
- 生成错题队列并做错题讲解。
- 生成变式题并跑通重做。

## 第 6 周：收尾可用版
- 做完成页和开门。
- 做异常页和重试。
- 处理 USB 断开提示和 AI 请求失败重试。
- 真机完整走测。
- 固定一套硬件和题型，准备演示版本。
